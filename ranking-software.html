Ranking Manuscript Writing Software

My extremely subjective ranking of the software I've used to write essays, research papers, reports, and other academic things.

Rankings are based on how much I personally enjoy using them, not their objective superiority. Please do not fight me.

Why I ranked them this way

S

Google Docs

My default for almost everything.

Google Docs is boring in the best possible way. I can open a document anywhere, share it with someone instantly, and generally trust that my work isn't going to disappear.

For essays and collaborative assignments, I honestly reach for Microsoft word first just because it's part of my school's subscription. But I had some classmates complain that they don't like using it. I usually would not succumb to this peer pressure. But Google docs is objectively better. Formatting could not be easier, they have a rule at the top for indentations, page numbers are easy to add, and they have TABS. That is the most big brain feature, thank you developers at google.

Things I like

  • Easy collaboration (no subscription needed)
  • Lots of font options
  • Has a tab feature
  • Formatting is nice & easy
  • Accessible from basically anywhere
  • Simple enough that I don't think about the software

Things I don't like

  • Why I gotta use my personal email?
  • Not ideal for very technical manuscripts (e.g., equations, models)
A

Microsoft Word

She's my second wife.

Word is best when collaborating in professional settings. In my opinion, formatting is more flexible compared to Docs because of the number of tools.

Things I like

  • Good for long academic papers
  • Track Changes is useful (not as detailed as Docs)
  • Looks better/more professional
  • Has automatic headings

Things I don't like

  • Formatting sometimes develops a mind of its own
  • Requires a Microsoft subscription
A

Notion

Great for thinking, less great for submitting.

I like Notion more for planning and organizing writing than for producing the final manuscript. It's especially nice when I have notes, outlines, sources, and drafts all living together. If you're indecisive, it's great because there's only 3 fonts and you don't worry about anything other than the words on the page.

B

Quarto

Extremely cool when I actually need it.

Quarto is much more technical than the other options here, but it's great when writing and data analysis need to live in the same document.

I wouldn't use it for every essay, but for reproducible research reports it makes much more sense. Tip is to write it on R Studio, otherwise previewing the paper and formatting is a headache.

C

Overleaf

I respect LaTeX more than I enjoy LaTeX.

Overleaf produces basic documents and makes LaTeX much easier to work with, but I rarely need enough mathematical formatting to justify writing everything in markup. I do like that it generates citations if you make a bibliography file. But again it requires a subscription.
